# 依頼: ワードソリティアゲーム開発（設計やり直し）

## ゲームコンセプト（確定）
英単語ゲームではなく、**日本語カード分類ソリティア**。
カードに書かれたワードを4列のカテゴリ列に仕分けするゲーム。

## レイアウト（全ステージ固定）
参考画像: 6D632733-5620-4FE7-A487-6971B6359336.png

- **左上**: 手数（残り移動回数をリボン形UIで表示）
- **中央上**: 山札エリア（表向きのカードが見えるスタック）
- **右上**: メイン山札（裏向き、残り枚数バッジ付き）
- **中央**: 4列の場
  - 上段: カテゴリスロット（初期1列にカテゴリカードあり、残り3列はロック）
  - 下段: 各列にカードスタック（上が裏向き、一番下が表向き）
- **下部**: ブースターボタン（ヒント・アンドゥ・特殊）

## ゲームルール
1. 初期状態で場に1枚カテゴリカードが配置されている
2. カテゴリカードは山札・場のカードにランダム混入
3. カテゴリカードをめくったら空いたカテゴリスロットに配置できる（新カテゴリ解放）
4. 通常カードは対応するカテゴリ列に配置する
5. 手数内にすべてのカードを配置できたらクリア

## 技術スタック
- Next.js 15 (App Router) / TypeScript / Tailwind CSS v4 / Framer Motion
- Turso (LibSQL) + Drizzle ORM
- Vercel ホスティング
- 将来: Capacitor 8 でモバイル化 → Google Play / App Store

## DB管理
- **カテゴリテーブル**: カテゴリID、カテゴリ名、アイコン等
- **カードテーブル**: カードID、カテゴリID、カード名（表示テキスト）等
- ステージ構成もDBで管理
